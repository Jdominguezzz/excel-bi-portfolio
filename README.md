# Excel & BI portfolio: business decisions from messy data

End-to-end BI projects in **Excel** (and later **Power BI**) across **finance** (banking, investments), **sports** (football, Formula 1) and **marketing** (paid media, growth, email, SEO).
Each project follows the same workflow: protect the raw file → profile and clean → model → analyse → check (reconcile to the source) → present → a one-page decision memo.

| # | Project | Niche | What it shows |
|---|---|---|---|
| 01 | [Credit-score risk bands](01-credit-risk-bands/) | Finance · banking | Cleaned a 60-loan book (a text score, a duplicate loan), banded customers by credit score with `IFS`, and showed Poor-score loans default 13× more often than Good-score loans, which shaped a lending cut-off and risk-based pricing recommendation. |

**Skills so far:** Excel Tables and structured references · data profiling and cleaning · `IFS` · `COUNTIFS` / `SUMIFS` / `AVERAGEIFS` · relative vs absolute references · honest charts · decision memos
**Coming next:** `XLOOKUP` · PivotTables and slicers · dynamic arrays · what-if analysis · Power Query · Power BI and DAX

Each project folder has the raw data, the `.xlsx` workbook, a screenshot, a `README.md` (question → approach → insight → recommendation → limitations) and a `memo.md`. All data is synthetic.
